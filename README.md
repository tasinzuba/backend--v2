# MediStore Backend v2

Medicine e-commerce backend with Better Auth and Nodemailer.

## Tech Stack

- Node.js + Express + TypeScript
- Prisma + PostgreSQL
- Better Auth
- Nodemailer

## Setup

```bash
npm install
npm run prisma:generate
npm run prisma:push
npm run dev
```

## Scripts

- `npm run dev` - Development server
- `npm run build` - Build for production
- `npm run seed` - Seed database
